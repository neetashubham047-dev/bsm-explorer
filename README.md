# 📈 BSM Explorer (Extended)

An interactive **Black–Scholes–Merton (BSM) Option Pricing & Greeks Explorer** built with **Python & Streamlit**.  
This app helps visualize **option prices, Greeks, implied volatility**, and sensitivity across strikes in real time.

---

## 🚀 Features

- ✅ Option Pricing (Call & Put)
- ✅ Full Greeks: Delta, Gamma, Vega, Theta, Rho
- ✅ Implied Volatility Calculator
- ✅ Strike-wise Sensitivity Analysis
- ✅ Interactive Charts
- ✅ Preset Save/Load
- ✅ CSV Upload Support
- ✅ Clean Dark-Themed UI

---

## 🛠 Tech Stack

- Python  
- Streamlit  
- NumPy, Pandas  
- SciPy  
- Matplotlib & Seaborn  
- Plotly  
- Yahoo Finance (optional live data)
